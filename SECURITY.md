# Security Policy

## Development status

Flower For You is in early development. Supported release versions and security-update commitments will be documented when formal releases begin.

## Reporting a vulnerability

Please do not publish exploitable security details in a public Issue.

Use GitHub's private vulnerability reporting feature if enabled. Otherwise, contact the project owner privately through the contact information on the repository profile.

Include a description, potential impact, reproduction steps, affected versions or commits, and a proof of concept if safe to provide.

Please allow reasonable time for investigation and a fix before public disclosure.
