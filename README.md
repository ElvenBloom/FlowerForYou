# Flower For You

**Every flower, for everyone.**

Flower For You is an open-source project building a procedural botanical generation toolkit for Unity. Its goal is to help game developers create a broad range of game-ready flowers and vegetation—from individual blooms and flowering plants to shrubs, bushes, and trees.

The project is being developed as a modular procedural system, not simply a library of premade models.

## Project status

**Early development · Pre-alpha**

The repository currently contains project documentation and planning. The first implementation milestone is the Petal Engine. Features listed below are planned unless explicitly marked as implemented.

**Planned project start:** November 11, 2026 · 11:11 AM IST (UTC+05:30)

## Vision

Make flexible, reusable botanical generation tools and generated assets freely available to everyone, especially people creating games.

## Planned capabilities

- Procedural petals with adjustable shape, taper, curvature, cup, twist, and thickness
- Flower assembly: receptacles, petal arrangements, stamens, pistils, and buds
- Leaves, stems, branching, and foliage
- Complete flowering plants, shrubs, bushes, and flowering trees
- Expandable species profiles supported by botanical references
- Realistic, stylized, and low-poly output styles
- Seed-based reproducible generation
- UVs, materials, mesh validation, LODs, wind animation, and export workflows

## Development principles

1. **Free to use:** project-generated assets should be freely available under the asset license.
2. **Procedural first:** build reusable geometry and assembly systems.
3. **Botanical structure matters:** represent meaningful differences in anatomy and growth.
4. **Game-ready:** consider performance, topology, materials, and practical export workflows.
5. **Modular:** individual generators should work independently and combine into larger plants.
6. **Reproducible:** saved settings and seeds should reproduce results wherever practical.
7. **Documented:** keep decisions, limitations, and progress understandable so development can resume after a pause.

## First milestone: Petal Engine

The first milestone is a reusable procedural petal mesh generator. It will focus on controllable shape parameters, reliable mesh construction, UVs, normals, bounds, and deterministic output.

## Botanical accuracy

This is a procedural graphics project, not a scientific authority. Species profiles should cite reliable botanical references, distinguish verified traits from procedural approximations, and document known variation.
