# Flower For You — Roadmap

This roadmap is directional. Priorities and scope may change as development progresses. An unchecked item is planned, not implemented.

## Foundation

- [x] Define project purpose and development principles
- [x] Establish contribution and governance guidelines
- [x] Establish source-code and generated-asset licensing policy
- [x] Prepare initial documentation structure
- [ ] Create the Unity package/project skeleton
- [ ] Add basic automated checks and tests

## Phase 1 — Petal Engine

- [ ] Procedural petal surface generation
- [ ] Shape, taper, curvature, cup, twist, and thickness controls
- [ ] Closed geometry and reliable edge profile
- [ ] UV, normal, and bounds validation
- [ ] Deterministic generation tests
- [ ] Initial petal presets

## Phase 2 — Flower Assembly

- [ ] Flower receptacle
- [ ] Petal placement and arrangement controls
- [ ] Stamens and pistils
- [ ] Bud and flower-stage generation
- [ ] Flower profiles and controlled variation

## Phase 3 — Leaves and Plants

- [ ] Leaf geometry and profiles
- [ ] Stems and branching
- [ ] Leaf attachment and orientation
- [ ] Complete plant assembly

## Phase 4 — Bushes and Trees

- [ ] Multi-stem shrub generation
- [ ] Branch hierarchy
- [ ] Flower and foliage distribution
- [ ] Tree and canopy generation

## Phase 5 — Game-production Features

- [ ] Realistic, stylized, and low-poly styles
- [ ] Polygon budgets and LODs
- [ ] Material and texture workflows
- [ ] Wind animation
- [ ] Export pipeline and runtime-generation options

## Phase 6 — Species Library

- [ ] Cited species profiles
- [ ] Expandable profile format
- [ ] Species data validation
- [ ] Documented species examples
